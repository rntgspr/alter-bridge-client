# alter-bridge client

macOS client for alter-bridge: the `alter-bridge` / `abg` CLI, the shared
protocol crate, native provider skills and hooks, and the client release
packaging.

- Install offline from a release archive: [INSTALL-OFFLINE.md](INSTALL-OFFLINE.md)
- Manual operation: [MANUAL.md](MANUAL.md)
- Static checks: `sh scripts/check.sh`
- Package a release: `scripts/client/package.sh v<workspace-version>`

The broker server is distributed separately as a container image.
